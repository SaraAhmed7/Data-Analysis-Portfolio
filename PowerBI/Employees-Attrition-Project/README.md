# 📊 Employee Attrition & Performance Dashboard

## 📌 Overview  
This project presents an interactive **Employee Attrition & Performance Dashboard** designed to analyze workforce data and provide actionable HR insights.  

The dashboard highlights key metrics such as attrition rate, employee distribution, salary trends, and hiring patterns to support better decision-making.

> 🎓 This dashboard was developed as a **Graduation Project during my training at the National Telecommunication Institute (NTI).**

---

## 🎯 Objectives  
- Analyze employee attrition and identify patterns  
- Monitor employee distribution across departments and countries  
- Understand salary variations and tenure trends  
- Track hiring trends over time  
- Provide clear insights for HR decision-making  

---

## 🛠️ Tools & Technologies  
- **SQL** → Data extraction and transformation  
- **Power BI** → Data visualization and dashboard creation  
- **Power Query** → Data cleaning and preprocessing  

---

## 📊 Dashboard Features  

### 🔹 KPIs Overview  
- Total Employees  
- Current Employees  
- Attrition Rate  
- Average Tenure  
- Average Annual Salary  

### 🔹 Department Analysis  
- Employee count by department  
- Average salary by department  
- Attrition rate by department  

### 🔹 Time-Based Insights  
- Monthly hiring trend  
- Hiring trend by quarter  

### 🔹 Geographical Analysis  
- Employee distribution by country (map visualization)  

### 🔹 Employee Insights  
- Relationship between tenure and salary  
- Gender distribution  

---

## 🚀 How to Use  
1. Open the dashboard file using Power BI  
2. Interact with filters (Department, Country, Business Unit)  
3. Explore insights and trends
