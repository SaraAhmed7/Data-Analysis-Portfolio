# 📊 Sales Analysis Dashboard

## 📌 Overview  
This project presents an interactive **Sales Analysis Dashboard** designed to analyze sales performance and uncover key business insights.  

The dashboard provides a comprehensive view of sales data, including revenue, quantity, customer behavior, and regional performance.

> 🎓 This dashboard was developed during my training at the **National Telecommunication Institute (NTI)** as part of my Data Analysis journey.

---

## 🎯 Objectives  
- Analyze overall sales performance  
- Identify top-performing categories and sub-categories  
- Track sales trends over time (monthly, quarterly, yearly)  
- Understand customer purchasing behavior  
- Compare performance across regions and cities  

---

## 🛠️ Tools & Technologies  

- **Excel** → Data cleaning, preprocessing, dashboard design and visualization 

---

## 📊 Dashboard Features  

### 🔹 KPIs Overview  
- Total Sales (2.3M)  
- Net Sales per Unit  
- Total Quantity Sold (38K)  

### 🔹 Sales Breakdown  
- Sales by Category  
- Sales by Sub-Category  
- Quantity by Sub-Category  

### 🔹 Location Analysis  
- Sales by Region  
- Sales by State  
- Sales by City  

### 🔹 Customer Insights  
- Sales by Customer  

### 🔹 Time-Based Analysis  
- Sales by Month  
- Sales by Quarter  
- Sales by Year  

### 🔹 Segment & Mode Analysis  
- Sales by Segment  
- Sales by Ship Mode  

---

## 🚀 How to Use  
1. Open the dashboard using Power BI  
2. Use the filters on the left panel (Region, Category, Segment, etc.)  
3. Explore insights interactively
